# 投资收益计算器

一个免费、简单的投资收益率与目标价格计算器。输入买入价，即可快速计算目标收益价格、当前收益率，以及亏损后回本所需的涨幅。

纯静态单文件（`index.html`），无需安装、无需构建，双击打开即可使用。

## 功能

- **目标价格**：输入买入价格和目标收益率（可选预设 +5% / +10% / +15% / +20% / +25% / +30% / +50% / +60%，或自定义），计算达到目标收益所需的价格。
- **快速目标价格表**：以上各档预设收益率对应的目标价格一览表，当前所选档位会高亮。
- **当前收益**：输入卖出/当前价格和投入本金，计算当前收益率与盈亏金额。
- **亏损回本**：输入亏损后的当前价格，计算当前亏损率，以及回到买入价所需的上涨幅度，并配有价格位置进度条。
- **公式速查**：页面底部列出全部计算公式，便于核对。

## 使用方法

无需安装依赖，用浏览器直接打开 `index.html` 即可（双击文件，或右键选择“用浏览器打开”）。

## 计算公式

| 名称 | 公式 |
| --- | --- |
| 收益率 | R = P₁ ÷ P₀ − 1 |
| 目标价格 | P₁ = P₀ × (1 + R) |
| 盈亏金额 | G = C × (P₁ ÷ P₀ − 1) |
| 回本涨幅 | X = P₀ ÷ P₁ − 1 |

其中 P₀ 为买入价格，P₁ 为当前/卖出价格，C 为投入本金，R 为收益率，X 为回本所需涨幅。

## 技术栈

纯 HTML + 内联 CSS + 原生 JavaScript，无框架、无依赖、无构建流程，全部逻辑都在 `index.html` 一个文件中。
